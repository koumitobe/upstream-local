# 上流力トレーニングシステム v2
## Claude Codeサブスク認証版（APIキー不要）

架空の顧客AIとヒアリングを行い、課題特定・要件定義・AIへの橋渡し力を鍛えるトレーニングツールです。
**既存のClaude Codeサブスクリプション枠を使用します。追加のAPIキー取得・課金は不要です。**

---

## 前提条件

- Node.js 18 以上
- Claude Code がインストール・ログイン済みであること
- `ANTHROPIC_API_KEY` 環境変数が **未設定** であること（設定するとAPI課金になります）

Claude Code のインストール・ログインがまだの場合:
\`\`\`bash
npm install -g @anthropic-ai/claude-code
claude login
\`\`\`

---

## クイックスタート

\`\`\`bash
# 1. 依存関係インストール
npm install

# 2. 動作確認（推奨）
npm run check

# 3. 起動
npm start
\`\`\`

ブラウザで http://localhost:3000 を開いてください。

---

## ⚠️ 重要：誰のサブスク枠を使うか

このサーバーを起動したPCの **Claude Codeログインアカウント** の枠を消費します。

| 運用パターン | 誰の枠を使うか |
|---|---|
| 受験者が自分のPCで `npm start` | 受験者自身の枠 |
| 管理者PCでサーバーを立てて複数人がブラウザでアクセス | 管理者の枠（同時受験は注意）|

**推奨:** 各受験者が自分のPCで起動する（枠を分散できる）

## トラブルシューティング

**「claude コマンドが見つかりません」**
→ `npm install -g @anthropic-ai/claude-code` を実行

**「認証エラー」**
→ `claude login` を実行してログインし直す

**「ANTHROPIC_API_KEY が設定されています」という警告が出る**
→ `unset ANTHROPIC_API_KEY`（Mac/Linux）または環境変数を削除（Windows）

**応答が遅い（30秒以上かかる）**
→ 正常です。`claude -p` コマンドの起動に数秒かかります。使用量が多い時間帯はさらに遅くなる場合があります。

**セッション上限に到達した場合**
→ リセットまで待つか、その日だけUsage Creditsで継続できます
