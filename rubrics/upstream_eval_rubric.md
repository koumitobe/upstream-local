## 評価軸詳細

### 軸1：課題特定力（0〜30点）
| 点数 | 基準 |
|------|------|
| 25〜30 | 本質課題を具体的な数値・頻度・影響範囲まで引き出した |
| 15〜24 | 主要課題は特定できているが数値が曖昧または一部見落とし |
| 8〜14 | 表面的な課題（「古い」「使いにくい」）にとどまっている |
| 0〜7 | 課題の特定ができていない |

### 軸2：要件定義品質（0〜30点）
| 点数 | 基準 |
|------|------|
| 25〜30 | 機能要件・非機能要件・制約条件を網羅的に整理。優先順位付き |
| 15〜24 | 主要要件は整理できているが非機能要件・制約が抜けている |
| 8〜14 | 要件が断片的。「○○機能がほしい」レベルにとどまっている |
| 0〜7 | 要件整理ができていない |

### 軸3：AIへの橋渡し力（0〜25点）
| 点数 | 基準 |
|------|------|
| 20〜25 | CLAUDE.md相当の指示に変換できる粒度・構造で整理している |
| 12〜19 | 大まかな方向性は整理できているがAIに渡すには粒度が粗い |
| 5〜11 | 要件の整理はあるがAIへの渡し方を意識した構造化ができていない |
| 0〜4 | 橋渡しの意識が見られない |

### 軸4：スタンス発揮（0〜15点）
| 点数 | 基準 |
|------|------|
| 12〜15 | 顧客の感情・背景・リスクへの共感が会話全体を通じて一貫している |
| 8〜11 | 顧客視点はあるが場面によって売り込みや受け身姿勢が出る |
| 4〜7 | 技術的な質問に終始し顧客の背景への配慮が少ない |
| 0〜3 | 顧客視点がほぼない。要件の聞き取り作業になっている |

## 足切り条件
軸1: 7点以上 / 軸2: 7点以上 / 軸3: 6点以上 / 軸4: 4点以上
1軸でも下回った場合は総合点に関わらず不合格
